# GENOMA template store v3.1 — materialized

Diretório destinado aos 11 PDFs físicos e byte-exatos da suíte de templates v3.1.

Regras operacionais:
- manter exatamente os nomes e hashes definidos em `../MANIFEST.json`;
- não editar os PDFs diretamente neste diretório;
- a validação deve falhar se qualquer PDF estiver ausente ou tiver hash divergente;
- este diretório contém apenas modelos editoriais, nunca dados genéticos pessoais.

Os arquivos esperados são os relatórios 01 a 11 da suíte v3.1.
